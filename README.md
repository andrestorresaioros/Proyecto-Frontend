# Proyecto Frontend — Tarjeta de presentación

Tarjeta de presentación web construida con HTML, CSS y JavaScript, sin frameworks ni dependencias externas.

## Contenido

- index.html — estructura de la tarjeta
- styles.css — estilos, tipografía y diseño responsive
- myCard.js — interactividad de la tarjeta
- Iconos/ — iconografía
- Imagenes/ — recursos gráficos

## Objetivo

Practicar maquetación, uso de tipografías, manejo de recursos gráficos e interacción básica con JavaScript.

## Ejecución

Abrir index.html en el navegador, o servir la carpeta:

    python -m http.server 8000
